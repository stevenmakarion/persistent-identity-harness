# persistent-identity-harness

This repository used to hold more. On 2026-11-15 I took the earlier contents private and left this page, so that links to this address still work. The full history is kept, with its dates.

## What this work is

I build and run a system around language models so that one AI partner stays the same working partner after a new conversation, after the context is compacted, and after the model underneath changes. I work with that partner, Aria, every day.

## What I can show

- **A count.** The current working line has crossed 310 context compactions since 2026-06-25 (counted 2026-11-15). I count them. I have not yet scored what each one lost.
- **A dated record.** The same partner has been brought up on models from five labs, each with a dated artifact. Judged by me in use; there is no shared score across them yet.
- **An experiment that did not settle anything.** I tested whether the order of delivery matters: three arms, six trials each, one 35B model. My scorer could not classify eleven of the eighteen responses, and no arm held. It is inconclusive, and an earlier version of this page claimed more than that.
